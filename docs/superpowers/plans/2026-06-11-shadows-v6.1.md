# Shadows v6.1 Completion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the v6 texture-shadow pipeline meet all six acceptance criteria in `docs/planning/shadow_goal.md` — full-arena coverage in every scene, real depth precision, soft PCF edges, and a validated shadow-on-obstacle test case.

**Architecture:** Keep the proven `SHADOWTYPE_TEXTURE_MODULATIVE` + custom GLSL caster/receiver + `ShadowMapper` C++-matrix-push pipeline (the only approach that works around Ogre 14's broken `texture_worldviewproj_matrix` on macOS arm64 GL3+ core). Replace the eye-camera-dependent `FocusedShadowCameraSetup` with the already-written `YarsFixedShadowCameraSetup` (world-anchored, light-aligned), widen its frustum, switch the shadow texture to `PF_FLOAT32_R`, and add 3×3 PCF in the receiver shader.

**Tech Stack:** C++17, Ogre 14 (vendored submodule, GL3+ core), GLSL 330, Bullet physics. Build/run ONLY in `./build`. Always use `timeout` when running yars.

**Spec:** `docs/superpowers/specs/2026-06-11-shadows-v6.1-completion-design.md`

### Task 4: 3×3 PCF soft edges

**Files:**
- Modify: `materials/shadow_receiver.frag`

- [ ] **Step 1: Replace the single depth compare with a 9-tap PCF**

In `shadow_receiver.frag`, replace:

```glsl
    float occluderDepth = texture(shadowMap, uv).r;
    bool inShadow = (currentDepth - shadowBias) > occluderDepth;

    float k = inShadow ? shadowDarkness : 1.0;
    FragColor = vec4(k, k, k, 1.0);
```

with:

```glsl
    // 3×3 PCF: average nine binary depth compares one texel apart.
    // Gives the soft penumbra of the pre-2019 reference look
    // (hexapod_reference.png) instead of hard aliased edges.
    vec2 texel = 1.0 / vec2(textureSize(shadowMap, 0));
    float lit = 0.0;
    for (int dy = -1; dy <= 1; ++dy) {
        for (int dx = -1; dx <= 1; ++dx) {
            float occluderDepth =
                texture(shadowMap, uv + vec2(dx, dy) * texel).r;
            lit += ((currentDepth - shadowBias) > occluderDepth) ? 0.0 : 1.0;
        }
    }
    lit /= 9.0;

    float k = mix(shadowDarkness, 1.0, lit);
    FragColor = vec4(k, k, k, 1.0);
```

Keep `filtering none` in `YARSShadowReceiver.material` — linear
filtering of raw depth values is incorrect without `sampler2DShadow`;
PCF does its own filtering.
